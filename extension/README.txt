Zeta Desktop Skin (Chrome extension)

Install once:
1. Keep this folder somewhere permanent, e.g. Documents\zeta-skin
2. Open chrome://extensions, switch on "Developer mode" (top right)
3. Click "Load unpacked" and pick this folder
4. Open https://zeta-ai.io in a window at least 1100px wide

Updates: when skin.js changes, the extension reloads itself within about 30 seconds.
Open Zeta tabs show "Zeta skin updated · refresh to apply" instead of reloading on their own.

Zen / Firefox:
Open about:debugging#/runtime/this-firefox, click "Load Temporary Add-on…" and pick manifest.json in this folder.
Firefox removes temporary add-ons when the browser restarts, so this has to be repeated after each restart.
